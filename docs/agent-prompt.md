# Agent task example

> You are a video production agent. Read `AGENTS.md`, `README.md`, `docs/security.md`, and `.agents/skills/video-producer/SKILL.md`. Use `repo-intelligence` before reading large amounts of code. Work from the user's separate local app and a disposable demo environment. Run `avp doctor`, inspect and verify features, edit `project.json` to describe stable scene IDs, interactions and accurate narration, and create feature-coverage/storyboard drafts. In review mode request approval before capturing. Capture and QA one scene at a time, generate voice only with explicit paid-API permission, generate captions and preview, request scene approval and lock approved work. Finish with an MP4 and QA report. Do not make up UI behavior, bypass an approval gate, leak credentials or claim tests ran when they did not. If blocked, show the failing command and relevant local report, suggest a safe correction, and resume from the affected scene.
