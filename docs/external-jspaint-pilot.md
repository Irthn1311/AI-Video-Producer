# External JS Paint pilot (CI pending)

Pinned [JS Paint](https://github.com/1j01/jspaint/tree/53be67ab8c47cc0d2168899e7481bc04839c4c81). Source inspection reveals the actual drawing surface is canvas.main-canvas, not an injected test ID or data-drawn flag. The app starts with the Pencil tool. The bounded adapter can now use a literal canvas class (no arbitrary CSS selectors) and read exact RGBA pixel counts for a visible 2D canvas of at most 2 million pixels. Before/after disjoint ranges on the same target and color can establish a pointer state transition. The interpreter evaluates a fixed read-only expression, not user-authored code. Evidence counts are not screenshot semantics or proof of a particular shape. No DOM/source modification or synthetic result. Existing attribute assertion remains supported.

The pilot loads tracked upstream browser assets at the pinned Git revision, verifies every served Git blob, binds a compact digest of assets to the AVP scanned source, serves the bytes in a read-only in-memory map with CSP and permissions restrictions. Symlinks are not served. CI uses a fresh loopback-only network namespace, unprivileged runner, cleared environment, no upstream npm scripts, credentials or external APIs. This is not a full host filesystem sandbox. JS Paint optional upload, collaboration, filesystem, microphone and desktop functions are out of scope.

Two fresh-context pencil drawings, actual before/after RGBA counts, adapter trial/rehearsal, real capture, technical QA, final, scoped caption repair, release preservation, video and receipt artifacts on success. No voice, paid API, independent semantic review, blindness, license redistribution conclusion or MathMate parity. Failure is a blocker, not a PASS. See CI for actual results.
