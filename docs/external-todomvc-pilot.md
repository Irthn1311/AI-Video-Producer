# External TodoMVC React pilot (candidate, CI pending)

Pinned upstream tastejs/todomvc ff43b02e59dfa604386bb382034b2cd07c2bcd8a, examples/react. Static source inspection exposed a missing AVP interaction: the Input component commits on Enter. Added bounded declarative locator press (single allowed key, no browser shortcuts/chords; not evidence itself) across validation, execution, adapter, storyboard and Build.

The external workflow obtains pinned source and checked-in browser bundle, never runs upstream npm scripts, serves only four unchanged browser assets with restrictive CSP, and executes in a fresh loopback-only Linux network namespace as an unprivileged user with cleared environment and fresh browser HOME. It does not claim full filesystem/OS sandbox or a licensing audit. Browser code is untrusted; no secrets, microphone, upload or real account. No upstream source is modified. Runtime assets are copied to a non-excluded scan directory so they affect the source fingerprint.

The pilot follows AVP analyze/skills/storyboard handoff, source-derived proposal, real rehearsal, freeze, capture/caption/preview/QA, final and a scoped narration-caption repair. It archives the prior video and checks unchanged capture/other preview hashes. Voice is disabled, no paid calls, no independent semantic pass. The author inspected source and authored the recipe; this is an external integration test, NOT a blind independent agent benchmark. Actual status comes from CI, not this document. If namespace setup or any action/gate fails, fail closed and report stage. The workflow retains only synthetic-data final/previous MP4s and output reports for seven days on success. JS Paint remains a separate pending trial.
