# Integrated Build validation

F-04e integrates the reviewed pointer adapter branch and the Creative Director, storyboard, voice/timing and visual design branches. The dedicated CI step runs two local fixture applications (inventory dashboard and canvas editor), not third-party benchmark repositories.

The test exercises source fingerprint and feature references, manually authored storyboard proposal, interactive creative/planning approvals, local audio import and selection, exact runtime browser rehearsal, visual plan, freeze, real Playwright capture, Remotion scene rendering, claim evidence QA, final FFmpeg concat and explicit review. The canvas fixture uses the reviewed bounded pointer adapter and before/after DOM assertions.

After an edit-only revision of the workflow shot, the test checks that old Build is blocked, new Build can be frozen using unchanged rehearsal/audio evidence, the first locked scene remains valid, and only the workflow preview changes; capture/voice hashes remain unchanged. It then corrupts selected audio and checks that Production fails closed. No Gemini call is made. Synthetic tones and scripted review confirmations test mechanics only, not natural narration, semantic quality or human listening. The fixture storyboard is authored in the test, not generated by an AI agent.

Run after installing dependencies, FFmpeg, Chromium and the Remotion browser:

```sh
AVP_INTEGRATED_SMOKE=1 node --test tests/integrated-build-smoke.test.mjs
```

Acceptance requires both fixture cases and all existing CI jobs to pass on the integration head. Unknown real apps, actual paid TTS, semantic review, cross-scene dependencies, independent shot repair and autonomous planning remain open; do not mark checklist criteria complete based on these fixtures alone.
