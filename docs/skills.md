# Skills index

A skill is **guidance to an AI coding agent**, not an executable dependency. Agent runtimes may not discover `.agents/skills/` automatically, so open files explicitly per `AGENTS.md`.

| Skill | Role |
|---|---|
| `video-producer` | Overall orchestration and review policy |
| `repo-intelligence` | Budgeted codebase research (Graphify optional) |
| `feature-coverage` | Decide/verify which capabilities to show |
| `storyboard-planner` | Scene plan, action script and narrative |
| `browser-capture` | Safe Playwright capture in demo environment |
| `scene-director` | Per-scene reviews, locks, QA and change impact |
| `ai-voiceover` | Optional TTS/languages and paid API consent |
| `video-editing` | Preview, render, editing priorities |
| `production-optimizer` | Cache, invalidation, budget-aware retries |
| `video-qa` | Technical and human quality gates |

Suggested Remotion official skills (third-party): `remotion-best-practices`, `remotion-create`, `remotion-render`, `remotion-captions`, `remotion-docs`, `remotion-markup`. Install separately from https://www.remotion.dev/docs/ai/skills subject to upstream license. We do **not** copy or vendor those skill implementations.
