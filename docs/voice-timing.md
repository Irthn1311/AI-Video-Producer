# Voice and timing rehearsal (F-04c)

Opt in using `"creative": {"timing": {"maxSilenceSec": 2, "actionToleranceSec": 0.25}}` in project.json (preserve other creative settings). This requires Build even if the older workflow flag is absent. Both thresholds are optional. Existing projects without the new policy are unaffected.

1. Resolve the actual `voiceover.voice`, `voiceover.style`, `voiceover.model`, and `language.narration`. Include pronunciation, accent, delivery and pace in style where appropriate. Creative brief guidance is not automatically translated into provider settings.
2. Select a representative scene first. Run `avp timing audition --scene ID --allow-paid-api` to synthesize its exact full narration. Paid API calls use the same persisted project budget and per-process call cap as legacy Production voice; cached exact requests are reused. Force requests still require explicit paid permission. No live paid call is performed by CI.
3. Alternatively, import an authorized local audio-only file with `avp timing import --scene ID --file FILE --confirm`. Confirm it contains the exact narration and represents the current voice settings. This is operator-declared provenance, not automated transcription. It is normalized to PCM WAV. To audition multiple voices, change actual voice settings and repeat; candidate history is retained by request/content hash. The selected audio must match the final settings.
4. Run `avp timing list --scene ID`, listen to the actual WAV, then `avp timing select --scene ID --hash HASH --confirm`. Repeat for all scenes with enabled voice. A locked scene must be unlocked before replacing its selection. Selection does not synthesize audio.
5. Rehearse browser actions with the existing authorized Build rehearsal commands. Run `avp timing check`. It checks current rehearsal action elapsed time, selected audio duration plus the existing 0.5s renderer tail, and longest detected silence. Audio and actions can run concurrently; their durations are not added. Overflow blocks readiness rather than assuming speedup. Silence detection measures amplitude, not linguistic content.
6. Revise narration/duration or choose new audio where required. Reprepare/reapprove/rehearse as necessary, then freeze Build. The timing digest binds selected audio receipts into the Build lock; selection changes invalidate freeze. Production voice copies the exact selected WAV without API calls. A Gemini key is not required in Production when all selected audio is available.
7. The agent must still inspect pronunciation, content, visual rhythm and actual audio/action alignment. This slice measures feasibility, not semantic sync or forced alignment. Actual production capture/evidence and QA remain mandatory.

Candidate files and selections live under .avp/timing, outside target source. Never include credentials or private narration. Local hashes are integrity checks, not remote attestations. No background provider calls, automated voice preference inference, short-text audition transfer, or automatic timeline compression is implemented.
