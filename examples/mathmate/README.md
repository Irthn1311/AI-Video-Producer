# MathMate historical case study

Historical source: [Coach Learning, branch `chore/archive-hackathon-video-20261110`](https://github.com/Phat-le2005/Coach_Learning/tree/chore/archive-hackathon-video-20261110/CoachLearningVideo).

The historical project used Playwright 1.64.1, Remotion 4.0.541, FFmpeg 7.1.1 and Gemini TTS to produce ~180-second and 203-second demos. It kept screenplay, TTS, Playwright capture scripts, Remotion source, subtitles and QA. AVP adapts that experience into portable skills and per-scene assets; it does not redistribute private files or assert that AVP generated the historical video.

Lessons: verify real UI/API behaviors, work in isolated demo environment, plan and review each scene, measure actual speech timing, use realistic accelerated waits, cache successful material, keep revisions and audit all render parameters.
